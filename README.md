# فانتازي الدوري الكويتي ⚽ — دوري زين الممتاز 2026/27

لعبة فانتازي كاملة على طراز Fantasy Premier League لكن بأندية ولاعبي الدوري الكويتي.
تعمل بالكامل محلياً في المتصفح — بدون خادم، بدون قواعد بيانات خارجية.

## التشغيل

```
cd kuwait-fantasy
python -m http.server 8137
```

ثم افتح http://localhost:8137

> لا تفتح `index.html` مباشرة بالنقر المزدوج — بعض الميزات تحتاج خادماً محلياً.

## أول استخدام
- **أول حساب يُسجّل يصبح مشرفاً تلقائياً** (يرى زر ⚙️ الإدارة).
- كوّن فريقك (15 لاعباً، ميزانية 100م، بحد أقصى 3 من كل نادٍ).
- من لوحة الإدارة ← الجولات: «بدء البث المباشر» يشغّل محاكاة حية للمباريات
  وتشوف النقاط تتحدث لحظياً في «مباشر». «احتساب وإغلاق» يحسم الجولة ويفتح التالية.

## البيانات الحقيقية
- الجولتان 1 و2 من نتائج **دوري زين الممتاز 2026/27** الفعلية (مصدر: ستادو).
- 4 مباريات من الجولة 2 معلّمة **«نتيجة تقديرية»** (النصر×التضامن، كاظمة×الشباب،
  الساحل×السالمية، الفحيحيل×الصليبيخات) — عدّلها من الإدارة ← النتائج والإحصاءات
  متى عرفت النتائج الصحيحة، وتُعاد كل النقاط تلقائياً.
- أسماء اللاعبين غير المعروفين (خارج هدّافي الجولتين وتشكيلات منصور) أسماء واقعية
  مُولّدة — عدّلها من الإدارة ← اللاعبون.

## الملفات
- `js/data.js` — البذرة: الأندية، اللاعبون، النتائج الحقيقية، نظام النقاط، القواعد، الأخبار
- `js/engine.js` — المحرك: الجدولة، توليد الإحصاءات، النقاط، الأسعار، الترتيب، المحاكاة الحية، المصادقة، الدوريات
- `js/views.js` — كل الشاشات · `js/admin.js` — لوحة الإدارة · `js/app.js` — التوجيه والهيكل
- `assets/crests/` — شعارات الأندية الـ12

## التخزين
كل شيء في `localStorage` بالمتصفح. نسخ احتياطي/استيراد من الإدارة ← البيانات.
«إعادة ضبط اللعبة» ترجع كل شيء للبذرة الأصلية.
