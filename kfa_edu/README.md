# موقع إدارة التعليم وتطوير الدارسين — الاتحاد الكويتي لكرة القدم

مشروع **مستقل تماماً** عن موقع mfsoccer: له إعدادات Netlify ودوال وقاعدة بيانات Firebase خاصة به،
ولا يعتمد على أي ملف خارج هذا المجلد. يمكن نقل المجلد كما هو إلى مستودع GitHub جديد.

## هيكل المجلد
```
kfa_edu/
├── netlify.toml              إعدادات النشر
├── site/                     الموقع (ما يراه الزوار)
│   ├── index.html · style.css · app.js
│   ├── config.js             الإعدادات والدورات المبدئية
│   ├── rules.js              قواعد السعر والتسجيل (مشتركة مع الخادم)
│   └── assets/               الشعارات والصور
└── netlify/functions/        الخادم
    ├── kfa-edu.js            الدورات والتسجيلات  ← /api/kfa-edu
    ├── kfa-pay.js            الدفع MyFatoorah    ← /api/kfa-pay
    └── lib/
```


## الأقسام
- **الرئيسية**: الدورات القادمة، الإحصاءات، خطوات التسجيل، الأسئلة الشائعة.
- **رزنامة الدورات**: عرض شهري أو قائمة، مع تصفية حسب المسار (رخص AFC، البراعم، حراس المرمى، الصالات، التخصصية).
- **التسجيل**: يتحقق من الرقم المدني (12 رقماً)، والهاتف الكويتي، والعمر 18+، وشرط الرخصة المسبقة، ويمنع تكرار التسجيل.
- **الدفع**: كي نت أو فيزا/ماستر أو Apple Pay عبر بوابة **MyFatoorah**، ثم إيصال قابل للطباعة.
- **طلباتي**: البحث برقم الطلب أو البريد مع الرقم المدني، وإكمال الدفع.
- **الإدارة** (`#admin`):
  - **الدورات:** إضافة، تعديل، نسخ دورة (تُنسخ كمسودة)، حذف، بحث وتصفية.
    لكل دورة: الحالة (منشورة/مغلقة/مسودة مخفية)، أيام الانعقاد (مثلاً الأحد والثلاثاء فقط)، التوقيت، المحاضر،
    اللغة، الفئة المستهدفة، المقاعد (0 = بلا حد) والمحجوز مسبقاً، فترة فتح/إغلاق التسجيل، سعر مبكر بتاريخ انتهاء،
    دورة مجانية (رسوم 0 = تسجيل بلا دفع)، الرخصة المطلوبة، المتطلبات والوصف.
  - **المسارات:** إضافة مسارات جديدة وتسميتها وتلوينها.
  - **استيراد من Excel:** قالب جاهز ← تعبئة ← رفع CSV مع معاينة قبل الحفظ (يحدّث الموجود ويضيف الجديد).
  - **التسجيلات:** تغيير الحالة وتصدير Excel.

## التشغيل محلياً
```
cd kfa_edu/site
python -m http.server 8137
```
ثم افتح http://localhost:8137 — يعمل في **الوضع التجريبي**: البيانات في المتصفح، ورمز الإدارة `adminPin` في `config.js`، والدفع محاكاة بلا تحصيل.

## النشر كموقع مستقل على Netlify
1. في Netlify: **Add new site ← Import an existing project** واختر هذا المستودع
   (أو انقل مجلد `kfa_edu` إلى مستودع جديد).
2. **Base directory:** `kfa_edu` — والباقي يُقرأ من `netlify.toml` تلقائياً (لا يوجد أمر بناء).
3. اربط النطاق الذي تريده (مثل `edu.kfa.com.kw`) من Domain settings.

## متغيرات البيئة (Site settings ← Environment variables)
| المتغير | الغرض | مطلوب؟ |
|---|---|---|
| `KFA_FIREBASE_SERVICE_ACCOUNT` | ملف JSON لحساب خدمة مشروع Firebase **جديد خاص بالموقع** (Firestore مفعّل) | نعم — بدونه يبقى تجريبياً |
| `KFA_ADMIN_KEY` | كلمة سر لوحة الإدارة | نعم |
| `MYFATOORAH_API_KEY` | مفتاح بوابة الدفع | للدفع الحقيقي |
| `MYFATOORAH_BASE` | `https://api.myfatoorah.com` للإنتاج (الافتراضي التجريبي `apitest`) | للدفع الحقيقي |
| `KFA_ALLOWED_ORIGINS` | نطاقات إضافية لروابط العودة من الدفع، مفصولة بفواصل | اختياري |

### إنشاء قاعدة البيانات (مرة واحدة)
1. console.firebase.google.com ← مشروع جديد ← **Firestore Database** ← Create (الموقع: أقرب منطقة).
2. القواعد: اترك Firestore **مقفلاً على الجميع** (`allow read, write: if false;`) — الموقع يكتب عبر الخادم فقط.
3. Project settings ← Service accounts ← **Generate new private key** ← الصق محتوى الملف كاملاً في `KFA_FIREBASE_SERVICE_ACCOUNT`.

### الدفع
حساب تاجر في MyFatoorah مع تفعيل KNET وVisa/Master وApple Pay، ثم ضع المفتاح أعلاه.
المبلغ لا يُقبل من المتصفح: يُحسب على الخادم وقت التسجيل ويُقرأ من الطلب المحفوظ.

## قبل الإطلاق
- الدورات والتواريخ والرسوم في `config.js` **نموذجية** — بعد ضبط Firebase أدخل الرزنامة المعتمدة من لوحة الإدارة أو استوردها من Excel.
- عدّل بيانات التواصل في `config.js`.
