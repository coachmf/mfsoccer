# موقع إدارة التعليم وتطوير الدارسين — الاتحاد الكويتي لكرة القدم

الرابط بعد النشر: `https://mfsoccer.com/kfa-edu/`

## الأقسام
- **الرئيسية**: الدورات القادمة، الإحصاءات، خطوات التسجيل، الأسئلة الشائعة.
- **رزنامة الدورات**: عرض شهري أو قائمة، مع تصفية حسب المسار (رخص AFC، البراعم، حراس المرمى، الصالات، التخصصية).
- **التسجيل**: يتحقق من الرقم المدني (12 رقماً)، والهاتف الكويتي، والعمر 18+، وشرط الرخصة المسبقة، ويمنع تكرار التسجيل.
- **الدفع**: كي نت أو فيزا/ماستر أو Apple Pay عبر بوابة **MyFatoorah**، ثم إيصال قابل للطباعة.
- **طلباتي**: البحث برقم الطلب أو البريد مع الرقم المدني، وإكمال الدفع.
- **الإدارة** (`#admin`):
  - **الدورات:** إضافة، تعديل، نسخ دورة (تُنسخ كمسودة)، حذف، بحث وتصفية.
    لكل دورة: الحالة (منشورة/مغلقة/مسودة مخفية)، أيام الانعقاد (مثلاً الأحد والثلاثاء فقط)، التوقيت، المحاضر،
    اللغة، الفئة المستهدفة، المقاعد (0 = بلا حد) والمحجوز مسبقاً، فترة فتح/إغلاق التسجيل، سعر مبكر بتاريخ انتهاء،
    دورة مجانية (رسوم 0 = تسجيل بلا دفع)، الرخصة المطلوبة، المتطلبات والوصف.
  - **المسارات:** إضافة مسارات جديدة وتسميتها وتلوينها.
  - **استيراد من Excel:** قالب جاهز ← تعبئة ← رفع CSV مع معاينة قبل الحفظ (يحدّث الموجود ويضيف الجديد).
  - **التسجيلات:** تغيير الحالة وتصدير Excel.

## التشغيل محلياً
```
python -m http.server 8137
```
ثم افتح http://localhost:8137/kfa-edu/ — الدفع هنا يعمل في **وضع تجريبي** (محاكاة بلا تحصيل).

## تفعيل البيانات المركزية (مطلوب قبل الإطلاق)
الدالة `netlify/functions/kfa-edu.js` تحفظ الدورات والتسجيلات في Firestore الموجود في الموقع
(`kfaedu/settings` و`kfaedu_regs/…`) بحساب الخدمة `FIREBASE_SERVICE_ACCOUNT` المضبوط أصلاً.
أضف في Netlify متغيراً واحداً: `KFA_ADMIN_KEY` = كلمة سر قوية لدخول لوحة الإدارة.
بعدها كل الأجهزة ترى نفس الدورات والطلبات، والمبلغ يُحسب على الخادم وقت التسجيل.
بدون ذلك (أو عند التشغيل المحلي) يعمل الموقع في الوضع التجريبي على تخزين المتصفح، ورمز الإدارة `adminPin` في `config.js`.

## تفعيل الدفع الحقيقي
1. افتح حساب تاجر في MyFatoorah وفعّل KNET وVisa/Master وApple Pay.
2. في Netlify ← Site settings ← Environment variables أضف:
   - `MYFATOORAH_API_KEY` = مفتاح الـAPI (سرّي)
   - `MYFATOORAH_BASE` = `https://api.myfatoorah.com` للإنتاج (بدونه يستخدم البيئة التجريبية `apitest`)
3. أعد النشر. الدالة: `netlify/functions/kfa-pay.js` على المسار `/api/kfa-pay`.

> المبلغ لا يُقبل من المتصفح: يُقرأ من طلب التسجيل المحفوظ على الخادم.

## قبل التشغيل الفعلي
- اضبط `KFA_ADMIN_KEY` في Netlify، وعدّل بيانات التواصل في `config.js`.
- الدورات والرسوم والتواريخ الحالية **نموذجية** — استبدلها بالرزنامة المعتمدة.
