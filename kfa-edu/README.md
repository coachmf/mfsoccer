# موقع إدارة التعليم وتطوير الدارسين — الاتحاد الكويتي لكرة القدم

الرابط بعد النشر: `https://mfsoccer.com/kfa-edu/`

## الأقسام
- **الرئيسية**: الدورات القادمة، الإحصاءات، خطوات التسجيل، الأسئلة الشائعة.
- **رزنامة الدورات**: عرض شهري أو قائمة، مع تصفية حسب المسار (رخص AFC، البراعم، حراس المرمى، الصالات، التخصصية).
- **التسجيل**: يتحقق من الرقم المدني (12 رقماً)، والهاتف الكويتي، والعمر 18+، وشرط الرخصة المسبقة، ويمنع تكرار التسجيل.
- **الدفع**: كي نت أو فيزا/ماستر أو Apple Pay عبر بوابة **MyFatoorah**، ثم إيصال قابل للطباعة.
- **طلباتي**: البحث برقم الطلب أو البريد مع الرقم المدني، وإكمال الدفع.
- **الإدارة** (`#admin`): تعديل حالات الطلبات، إضافة الدورات وتعديلها، تصدير Excel (CSV).

## التشغيل محلياً
```
python -m http.server 8137
```
ثم افتح http://localhost:8137/kfa-edu/ — الدفع هنا يعمل في **وضع تجريبي** (محاكاة بلا تحصيل).

## تفعيل الدفع الحقيقي
1. افتح حساب تاجر في MyFatoorah وفعّل KNET وVisa/Master وApple Pay.
2. في Netlify ← Site settings ← Environment variables أضف:
   - `MYFATOORAH_API_KEY` = مفتاح الـAPI (سرّي)
   - `MYFATOORAH_BASE` = `https://api.myfatoorah.com` للإنتاج (بدونه يستخدم البيئة التجريبية `apitest`)
3. أعد النشر. الدالة: `netlify/functions/kfa-pay.js` على المسار `/api/kfa-pay`.

> **مهم:** المبلغ يُحسب على الخادم من `kfa-edu/config.js` وليس من المتصفح.
> لتغيير الرسوم أو إضافة دورة مدفوعة: عدّل `seedCourses` في `config.js` وارفع التغيير
> (التعديل من لوحة الإدارة وحده لا يكفي للدفع الحقيقي).

## قبل التشغيل الفعلي
- غيّر `adminPin` وبيانات التواصل في `config.js`.
- التخزين حالياً في المتصفح (localStorage)، أي أن لوحة الإدارة ترى طلبات الجهاز نفسه فقط.
  للتشغيل الفعلي يجب نقل الطلبات إلى قاعدة بيانات مركزية (مثل Firestore المستخدم في الموقع).
- الدورات والرسوم والتواريخ الحالية **نموذجية** — استبدلها بالرزنامة المعتمدة.
